# FairShift TrustLoop

### A Decent Work and Workplace Transparency Platform

FairShift TrustLoop is a web application built for **PromptWars**, organised by the ACM Student Chapter at SRMIST. The project addresses the challenge **"FairShift – A Decent Work Platform for Employee-Intensive Organisations"**, aligned with **UN Sustainable Development Goal 8: Decent Work and Economic Growth**.

## 🌐 Live Demo

https://fairshiftloop.vercel.app

## 🎯 Problem Statement

Employees in employee-intensive organisations may face challenges related to workplace grievances, salary transparency, overtime calculations, and leave management. FairShift TrustLoop aims to make these processes easier to access and understand through a single digital platform.

## 💡 Our Solution

FairShift TrustLoop brings essential workplace support features together in one web application. It aims to promote transparency, simplify workplace processes, and provide an accessible interface for employees and administrators.

## ✨ Features

- **Anonymous Grievance Reporting:** Provides an interface for employees to report workplace concerns.
- **FairPay:** Helps users understand salary and overtime information.
- **Leave Management:** Provides a way to manage leave requests and track their status.
- **Admin Dashboard:** Offers an interface for reviewing and organising workplace concerns.
- **User-Friendly Interface:** Designed to make workplace information and processes easier to navigate.

## 🛠️ Technologies Used

- **Lovable:** Used to build and develop the web application.
- **Web Technologies:** Frontend technologies used to create the application's interface and functionality.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL.git
   ```

2. Open the project folder:

   ```bash
   cd fairshift-trustloop
   ```

3. Install the required dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to access the application.
